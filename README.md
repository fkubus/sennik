# Sennik

Polski serwis — słownik snów z płatną, spersonalizowaną interpretacją snów
przez AI. Szczegóły projektu, komendy i konwencje: patrz [`CLAUDE.md`](./CLAUDE.md).

## Szybki start

```bash
cp .env.example .env.local   # uzupełnij zmienne środowiskowe
pnpm install
pnpm dev
```

Aplikacja domyślnie działa pod [http://localhost:3000](http://localhost:3000).
